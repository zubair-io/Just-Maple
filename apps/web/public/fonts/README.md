# Material Symbols Rounded

Source: [Google Material Design Icons](https://github.com/google/material-design-icons/tree/10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7/variablefont),
revision `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`.

`MaterialSymbolsRounded[FILL,GRAD,opsz,wght].woff2` was instantiated with
FontTools 4.62.1 at FILL=0, GRAD=0, opsz=24, wght=400 (the app's existing icon
appearance). All glyphs/ligatures are retained. The 450,864-byte static font avoids
shipping unused variable axes. Apache 2.0 license is in
`material-symbols-LICENSE.txt`.

SHA-256: `dcedb5d34c36d2c7b16671e3496f05d540f76c93fdfa4bfe273a0fc647e79086`.

The filename is content-addressed. When updating, also update the preload in
`src/index.html` and the font-face in `src/styles.scss`. The service worker prefetches
the font with the app shell so icon rendering does not need a third-party request.
