Additional sources and adaptations:

- `Just-Maple/ds-bundle/tokens/maple-tokens.css` → `theme/just-maple-tokens.css`, unchanged reference. Its light root and dark-selector tokens are registered in `theme/theme.css`.
- `_Maple/.../generated/_ui-tokens.scss` → `theme/_maple-dark-tokens.scss` is retained only as a historical reference. It no longer supplies production colors; both appearance modes use Just-Maple tokens.
- `_Maple` tokens.scss is retained as `theme/_maple-typography-reference.scss`; its text scale and typography utilities are extracted unchanged. `scripts/generate-ui-theme.py` reproducibly generates both light and dark colors from the checked-in Just-Maple reference, with existing typography utilities retained. The generated combined `theme/theme.css` registers shared semantic Tailwind v4 tokens and follows the operating system appearance by default, with data-theme light/dark selectors for explicit appearance and visual validation. Missing light semantic counterparts use the matching Just-Maple palette. No new per-screen theme system.
- `Just-Maple/apps/web/public/maple-leaf.svg` → `src/web/public/maple-leaf.svg`, the original Just Maple leaf retained from the previous app.
- Lato, Merriweather and JetBrains Mono fonts and their OFL licenses are copied unchanged from `_Maple/.../src/assets/fonts` into the shared library `src/assets/fonts`. Font-face metric overrides are retained from `_Maple` fonts.scss; URLs are adapted for the library.
- `Just-Maple/apps/apple/JapaneseMaple/CustomSchemeHandler.swift` → `src/apple/Just Maple/Host/CustomSchemeHandler.swift`. Adaptations: remove request/path logging, constrain local scheme/host and resolved bundle paths, and use main-actor isolation.
- `src/web/src/app` contains Just Maple feature compositions using the extracted components. Existing native command behavior was ported from the previous WebView UI; the old HTML-string renderer and DOM reconciler are excluded.

The extraction builds as `@maple/ui` with `npm run build:ui --prefix src/web`. No donor photo, server, cloud account, Meilisearch, telemetry, or unrelated business models were imported. Cross-repository adoption/version publishing remains future work.

September 27 Today/Sources adaptation: shared button primary foreground uses `--color-on-primary`, derived from JustMaple’s light snow token, while active labels and keyboard rings use readable semantic aliases. This fixes contrast in both modes without changing the donor repository. Feature pages add no independent palette.
