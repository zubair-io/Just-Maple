# Collectibles & LEGO Tracking

Just Maple includes specialized features for tracking collectible items, with deep integration for LEGO sets via the Rebrickable database.

## Overview

### What You Can Track

- LEGO sets and minifigures
- Other collectibles (extensible)
- Status (have, want, sold)
- Quantities
- Custom notes

### Key Features

- Barcode scanning
- Database integration
- Status management
- Collection statistics

## LEGO Tracking

### Getting Started

1. Create or open a notebook
2. Navigate to LEGO section
3. Start scanning or searching

### Finding Sets

Multiple ways to add sets:

#### Barcode Scanning

1. Click "Scan"
2. Point camera at LEGO box barcode
3. Set is identified and added
4. Confirm details

#### Search

1. Click "Search"
2. Enter set name, number, or theme
3. Select from results
4. Add to collection

#### Manual Entry

1. Click "Add Manual"
2. Enter set number (e.g., 75192)
3. Details pulled from Rebrickable
4. Confirm and save

### Set Information

For each set, see:

- **Image** - Official set photo
- **Name** - Full set name
- **Number** - LEGO set number
- **Theme** - Category/theme
- **Piece count** - Number of pieces
- **Year** - Release year
- **Price** - MSRP (if available)

## Status Management

### Status Options

| Status   | Meaning                    |
| -------- | -------------------------- |
| **Have** | You own this set           |
| **Want** | On your wishlist           |
| **Sold** | Previously owned, now sold |
| **None** | Tracking but no status     |

### Changing Status

1. Find the set in your list
2. Click the status button
3. Select new status
4. Optional: Add notes (condition, price paid)

### Quantities

Track multiple copies:

- Set quantity for sets you own
- Track sealed vs. built
- Note locations if stored separately

## Collection Views

### List View

See all items in a sortable list:

- Filter by status
- Sort by name, number, year, theme
- Quick status changes

### Grid View

Visual gallery of your collection:

- Thumbnail images
- Status indicators
- Click for details

### Statistics

View collection stats:

- Total sets
- Total pieces
- By status (have/want/sold)
- By theme
- Estimated value

## Barcode Scanner

### Using the Scanner

1. Tap the scan button
2. Grant camera permission
3. Point at barcode
4. Hold steady until recognized

### Supported Barcodes

- UPC codes (LEGO boxes)
- EAN codes
- Set numbers (manual entry)

### Scanner Tips

- Good lighting helps
- Flat, undamaged barcodes work best
- Try different angles if not scanning
- Fall back to search if needed
