# AI Writing Assistant

Just Maple's AI writing assistant helps you write better, faster. Powered by Claude, it can continue your thoughts, improve clarity, expand ideas, and more.

## Getting Started

### Accessing AI Features

1. Select text in the memo editor
2. The AI toolbar appears above the selection
3. Choose an action or enter a custom prompt

### Available Actions

| Action        | Description                          |
| ------------- | ------------------------------------ |
| **Continue**  | Auto-complete your text naturally    |
| **Improve**   | Enhance clarity and readability      |
| **Simplify**  | Reduce complexity, use simpler words |
| **Expand**    | Add detail, examples, and depth      |
| **Shorten**   | Make text more concise               |
| **Summarize** | Create a 2-3 sentence summary        |
| **Grammar**   | Fix spelling and grammar errors      |
| **Translate** | Convert to another language          |
| **Custom**    | Enter your own instruction           |

## Using AI Actions

### Continue Writing

When you're stuck or want to keep a thought going:

1. Place cursor at the end of your text
2. Click "Continue" in the AI toolbar
3. AI generates the next sentences
4. Accept, edit, or regenerate

### Improve Text

Make existing text clearer and more readable:

1. Select the text to improve
2. Click "Improve"
3. AI rewrites for better flow and clarity
4. Review changes before accepting

### Simplify

Reduce reading level and complexity:

1. Select complex or technical text
2. Click "Simplify"
3. AI uses simpler words and shorter sentences
4. Good for making content accessible

### Expand

Add more detail and examples:

1. Select a brief passage
2. Click "Expand"
3. AI adds explanations, examples, context
4. Useful for fleshing out outlines

### Shorten

Make text more concise:

1. Select verbose text
2. Click "Shorten"
3. AI removes redundancy, tightens prose
4. Maintains key information

### Summarize

Get a quick overview:

1. Select a long passage or document
2. Click "Summarize"
3. AI produces a 2-3 sentence summary
4. Great for creating TL;DRs

### Grammar Check

Fix errors without changing meaning:

1. Select text to check
2. Click "Grammar"
3. AI fixes spelling, punctuation, grammar
4. Preserves your voice and style

### Translate

Convert to another language:

1. Select text to translate
2. Click "Translate"
3. Choose target language
4. AI translates while preserving meaning

### Custom Instructions

When preset actions aren't enough:

1. Select text
2. Click "Custom"
3. Type your instruction (e.g., "Make this more formal")
4. AI follows your specific guidance

## Real-time Streaming

### How It Works

AI responses stream in real-time:

- See text appear word by word
- Cancel if going in wrong direction
- Faster than waiting for full response

### Cancel & Regenerate

- Click "Stop" to cancel mid-stream
- Click "Regenerate" for a different result
- Each regeneration may vary

## Context Awareness

### Document Context

The AI understands:

- Content before and after selection
- Document title and structure
- Overall tone and style

### Better Results

For best results:

- Select enough context
- Be specific with custom prompts
- Iterate with regenerate

## Usage & Limits

### Rate Limiting

To ensure fair use:

- Daily usage limits per user
- Check remaining quota in settings
- Limits reset at midnight UTC

### Checking Usage

1. Go to Settings
2. Click "AI Usage"
3. See tokens used and remaining

## Tips & Best Practices

### Effective Prompts

- Be specific: "Make this more formal for an executive audience"
- Give context: "This is for a technical blog post"
- Iterate: Try different approaches

### When to Use AI

| Good For                  | Not Ideal For              |
| ------------------------- | -------------------------- |
| First drafts              | Final fact-checking        |
| Overcoming writer's block | Highly specialized content |
| Rephrasing ideas          | Original creative voice    |
| Grammar and clarity       | Sensitive communications   |

### Review AI Output

Always review and edit AI suggestions:

- Check factual accuracy
- Ensure it matches your intent
- Maintain your authentic voice

## Privacy

### How Data is Handled

- Text sent to AI is processed securely
- No training on your content
- Responses not stored long-term
- All processing via your server

### Self-Hosted Privacy

When self-hosted:

- Configure your own API keys
- Full control over AI provider
- No data leaves your infrastructure
