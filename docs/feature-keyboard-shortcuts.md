# Keyboard Shortcuts

Just Maple supports comprehensive keyboard shortcuts for efficient navigation and editing. Use these shortcuts to work faster without reaching for your mouse.

## Global Shortcuts

Available anywhere in the app:

| Action           | macOS             | Windows/Linux      |
| ---------------- | ----------------- | ------------------ |
| Search           | `Cmd + K`         | `Ctrl + K`         |
| New document     | `Cmd + N`         | `Ctrl + N`         |
| Toggle sidebar   | `Cmd + \`         | `Ctrl + \`         |
| Toggle dark mode | `Cmd + Shift + D` | `Ctrl + Shift + D` |
| Settings         | `Cmd + ,`         | `Ctrl + ,`         |
| Quick switch     | `Cmd + P`         | `Ctrl + P`         |

## Navigation

| Action       | macOS             | Windows/Linux        |
| ------------ | ----------------- | -------------------- |
| Go back      | `Cmd + [`         | `Alt + Left`         |
| Go forward   | `Cmd + ]`         | `Alt + Right`        |
| Close tab    | `Cmd + W`         | `Ctrl + W`           |
| Next tab     | `Cmd + Shift + ]` | `Ctrl + Tab`         |
| Previous tab | `Cmd + Shift + [` | `Ctrl + Shift + Tab` |

## Markdown Shortcuts

Type these and press Space:

| Markdown   | Result          |
| ---------- | --------------- |
| `#`        | Heading 1       |
| `##`       | Heading 2       |
| `###`      | Heading 3       |
| `-` or `*` | Bullet list     |
| `1.`       | Numbered list   |
| `[]`       | Task item       |
| `>`        | Blockquote      |
| ` ``` `    | Code block      |
| `---`      | Horizontal rule |

## Customizing Shortcuts

### Current Limitations

Shortcuts are currently not customizable. This feature is planned for a future release.

### Conflict Resolution

If a shortcut conflicts with your OS or browser:

- OS shortcuts take precedence
- Consider using different shortcuts
- Report conflicts for future fixes

## Tips

### Learning Shortcuts

- Start with the most common (search, formatting)
- Add new shortcuts gradually
- Print this page for reference

### Efficiency

- Combine shortcuts for complex actions
- Use markdown shortcuts for speed
- Keep hands on keyboard when writing
