# Transcription

Just Maple provides AI-powered transcription for your voice recordings, turning audio into searchable, editable text.

## How Transcription Works

### Automatic Processing

1. You complete a recording
2. Audio is processed through WhisperKit
3. Transcript appears alongside the audio
4. Words are timestamped for precise navigation

### On-Device Processing

Transcription runs locally on your device:

- **Privacy** - Audio never leaves your device for transcription
- **Speed** - No network latency for processing
- **Offline** - Works without internet connection

## Using Transcripts

### Viewing Transcripts

Open any completed recording to see the transcript:

- Full text display below the audio player
- Timestamps shown for each segment
- Speaker labels (if detected)

### Interactive Playback

Click any word in the transcript to:

- Jump to that moment in the audio
- Hear the exact context
- Verify accuracy

### Synchronized Highlighting

During playback:

- Current word is highlighted
- Auto-scroll follows along
- Easy to read while listening

## Transcript Features

### Word-Level Timing

Each word has precise timestamps:

- Jump to any word by clicking
- Export with timestamps
- Create clips from specific sections

### Confidence Scores

The AI indicates certainty:

- High confidence - Clear, accurate words
- Low confidence - May need verification
- Visual indicators for uncertain sections

### Speaker Detection

When available:

- Different speakers labeled
- Useful for meetings and interviews
- Color-coded by speaker

## Editing Transcripts

### Making Corrections

Click on any word to edit:

1. Select the incorrect text
2. Type the correction
3. Changes save automatically

### Why Edit?

- Fix AI misheard words
- Add proper nouns and names
- Correct technical terminology

## Searching Transcripts

### Full-Text Search

Transcript text is indexed for search:

- Search across all recordings
- Find specific topics or phrases
- Results link directly to the audio moment

### Filters

- Search within single recording
- Filter by date range
- Limit to specific notebooks

## Export Options

### Export Formats

- **Plain text** - Just the words
- **Timestamped** - Text with time codes
- **SRT/VTT** - Subtitle formats
- **Markdown** - Formatted with speakers

### Export Use Cases

- Create meeting notes
- Generate subtitles for video
- Archive for other systems

## Supported Platforms

### Native Apps (Recommended)

- **iOS** - Full WhisperKit integration
- **macOS** - Full WhisperKit integration
- On-device processing
- Best accuracy and speed

### Web

- Server-side processing option
- Requires API configuration
- Falls back to cloud services

## Tips for Better Transcription

### Recording Quality

- Speak clearly and at moderate pace
- Minimize background noise
- Use a good quality microphone
- Avoid crosstalk in group recordings

### Vocabulary

- Common words transcribe best
- Spell out unusual terms first time
- Add corrections for learning

### Post-Processing

- Review important transcripts
- Correct key names and terms
- Use edited transcripts for references
