## AI Writing Assistant

The AI Writing Assistant provides inline AI-powered writing help directly within the memo editor.

### Features

- **9 AI Actions:**
    - `/ai continue` - AI continues writing from cursor
    - `/ai improve` - Enhance clarity and readability
    - `/ai simplify` - Make text easier to understand
    - `/ai summarize` - Generate summary
    - `/ai grammar` - Fix spelling/grammar
    - `/ai expand` - Add more detail
    - `/ai shorten` - Make more concise
    - `/ai translate` - Translate to another language
    - `/ai custom` - Custom instructions

### UI/UX

- Real-time streaming with typing cursor animation
- Accept/Reject workflow (Enter/Escape)
- Keyboard shortcut: `Cmd/Ctrl+J` to open AI menu
- Rate limiting: 50 requests/day free tier

### Architecture

- SSE (Server-Sent Events) for streaming responses
- Uses existing Claude bot configuration from notebook
- Integrates with TipTap editor via custom events

### API Endpoints

| Endpoint                       | Method | Description            |
| ------------------------------ | ------ | ---------------------- |
| `/api/ai/generate/:notebookId` | POST   | SSE streaming endpoint |

### Files

| Location                                                  | Purpose                                   |
| --------------------------------------------------------- | ----------------------------------------- |
| `apps/api/src/routes/ai.ts`                               | SSE streaming endpoint                    |
| `apps/api/src/services/ai-writing.service.ts`             | Prompt templates & Claude API integration |
| `apps/api/src/repositories/ai-usage.repo.ts`              | Usage tracking with rate limiting         |
| `apps/web/src/app/services/ai-writing.service.ts`         | SSE client service                        |
| `apps/web/src/app/components/molecules/ai-preview-panel/` | Streaming preview with accept/reject      |

## Bi-directional Linking

Wiki-style linking system that allows pages to reference each other with automatic backlink tracking.

### Features

- **Wiki-style Syntax:** `[[Page Name]]` with autocomplete
- **Slash Commands:** `/page link` and `/page embed`
- **Backlink Tracking:** Automatic tracking on content changes
- **Link Metadata:** Stored on Page schema (`linksMeta`)
- **Page Link Navigation:** Click to navigate
- **Search Modal:** Keyboard navigation (↑↓ Enter Escape)
- **Create New Pages:** From link search
- **Backlinks Panel:** With unlinked mentions section

### API Endpoints

| Endpoint                        | Method | Description                       |
| ------------------------------- | ------ | --------------------------------- |
| `/api/links/search`             | GET    | Autocomplete page search          |
| `/api/links/:pageId/backlinks`  | GET    | Get pages linking to this page    |
| `/api/links/:pageId/forward`    | GET    | Get pages this page links to      |
| `/api/links/:pageId/unlinked`   | GET    | Find text mentions not yet linked |
| `/api/links/graph`              | GET    | Full knowledge graph data         |
| `/api/links/graph/page/:pageId` | GET    | Local graph around a page         |
| `/api/links/reindex`            | POST   | Bulk reindex all links            |

## Memo Versioning

Complete version history system for memos that provides a safety net for editing.

### Features

- **Auto-save Versions:** Every 5 minutes of active editing
- **Manual Checkpoints:** `Cmd/Ctrl+S` saves with toast notification
- **Version History Panel:** Slide-in panel from note header
- **Version Preview:** Renders Y.js content as styled HTML
- **Restore Functionality:** Non-destructive (creates backup before restore)
- **Gzip Compression:** Compresses states >1KB if it saves >10% space
- **Tiered Retention:** 24h all → 7d hourly → 30d daily → 90d weekly
- **Deduplication:** Skips snapshot if content unchanged

### Version Triggers

| Trigger              | When                          |
| -------------------- | ----------------------------- |
| `auto-interval`      | Every 5 minutes of editing    |
| `auto-idle`          | After 30 seconds idle         |
| `manual`             | `Cmd/Ctrl+S` or explicit save |
| `ai-edit`            | Before AI modifies content    |
| `significant-change` | Large content changes         |

### API Endpoints

| Endpoint                                         | Method | Description               |
| ------------------------------------------------ | ------ | ------------------------- |
| `/api/memos/:noteId/versions`                    | GET    | List versions (paginated) |
| `/api/memos/:noteId/versions/:versionId`         | GET    | Get version with state    |
| `/api/memos/:noteId/versions/:versionId/restore` | POST   | Restore version           |
| `/api/memos/:noteId/versions`                    | POST   | Create manual checkpoint  |

### Storage Optimization

- **Compression:** Gzip for states >1KB
- **Threshold:** Only use compression if >10% savings
- **Limits:** 200 versions max, 50MB max per memo

### Files

| Location                                                 | Purpose                               |
| -------------------------------------------------------- | ------------------------------------- |
| `apps/api/src/routes/memo-versions.ts`                   | REST API endpoints                    |
| `apps/api/src/repositories/memo-version.repo.ts`         | CRUD operations with gzip compression |
| `apps/api/src/services/memo-version.service.ts`          | Auto-snapshot logic, retention policy |
| `apps/web/src/app/services/memo-version.service.ts`      | API client service                    |
| `apps/web/src/app/components/molecules/version-history/` | Version history panel                 |
| `packages/shared/src/schemas/memo-version.ts`            | TypeBox schemas                       |

## Full-text Search

Full-text search across memos, whiteboards, and messages with highlighted snippets.

### Features

- **Cross-Content Search:** Memos, whiteboards, messages
- **Highlighted Snippets:** Shows matching text in context
- **Access Control:** Respects notebook sharing permissions
- **Filters:** By type and notebook
- **Keyboard Navigation:** Cmd/Ctrl+K to open, ↑↓ to navigate, Enter to select
- **Recent Searches:** Stored in localStorage
- **Auto-indexing:** Keeps index up-to-date via hooks on page CRUD and Y.js content saves

### API Endpoints

| Endpoint              | Method | Description                |
| --------------------- | ------ | -------------------------- |
| `/api/search`         | GET    | Search with query, filters |
| `/api/search/reindex` | POST   | Rebuild search index       |

### Search Index

- **Title Weight:** 10x priority
- **Content Weight:** 1x priority
- **Updates:** On page create, update, delete, trash, restore

### Files

| Location                                              | Purpose                              |
| ----------------------------------------------------- | ------------------------------------ |
| `apps/api/src/routes/search.ts`                       | API endpoints                        |
| `apps/api/src/services/search.service.ts`             | Search service with access control   |
| `apps/api/src/repositories/search.repo.ts`            | Y.js text extraction and indexing    |
| `apps/web/src/app/services/search.service.ts`         | Angular search service with debounce |
| `apps/web/src/app/components/organisms/search-modal/` | Search modal component               |
| `packages/shared/src/schemas/search.ts`               | TypeBox schemas                      |

### Building Initial Index

To build the initial search index for existing content:

```bash
bun run apps/api/src/scripts/build-search-index.ts
```

## MCP Server

Model Context Protocol (MCP) server integrated into the Just Maple API that allows Claude.ai and other MCP clients to interact with notebooks, pages, memos, and whiteboards.

### Endpoint

```
https://paperbark.justmaple.app/mcp
```

### Authentication

Uses the existing JWT authentication system. Clients send a Bearer token, and the `sub` claim identifies the user.

### Available Tools

| Tool                  | Description                                            |
| --------------------- | ------------------------------------------------------ |
| `list_notebooks`      | List all notebooks the user has access to              |
| `get_notebook`        | Get details of a specific notebook                     |
| `list_pages`          | List pages (filterable by notebook or type)            |
| `get_page`            | Get page details including content                     |
| `search_pages`        | Search pages by title or content                       |
| `create_page`         | Create a new memo or whiteboard                        |
| `update_page`         | Update title, move to notebook, favorite/archive/trash |
| `get_memo_content`    | Extract text content from a memo's Y.js state          |
| `update_memo_content` | Update memo text content                               |
| `get_whiteboard`      | Get whiteboard elements                                |
| `update_whiteboard`   | Update whiteboard elements                             |

### Protocol Support

- **Transport:** Streamable HTTP (MCP spec 2025-03-26)
- **Methods:** POST (messages), GET (SSE stream), DELETE (terminate session)
- **Session:** Managed via `Mcp-Session-Id` header with 24-hour expiry
- **OAuth Metadata:** `/.well-known/oauth-protected-resource`

### Files

| Location                     | Purpose                             |
| ---------------------------- | ----------------------------------- |
| `apps/api/src/routes/mcp.ts` | MCP protocol handler with all tools |

### Usage with Claude.ai

1. Deploy the API
2. In Claude.ai: Settings → Integrations → Add Custom Connector
3. URL: `https://paperbark.justmaple.app/mcp`
4. Configure OAuth to issue JWTs with user `_id` as `sub`

## Database Indexes

The following indexes were added to support the new features:

### Templates Collection

- `id` (unique)
- `userId, updatedAt` (compound)
- `isSystem`
- `category`

### Memo Versions Collection

- `noteId, createdAt` (compound, descending)
- `noteId, version` (compound)

### Search Index Collection

- `title, plainText` (text index with weights)
- `pageId` (unique)
- `notebookId`
- `type`
- `updatedAt`

## Migration Notes

When upgrading to v0.9, ensure:

1. **Dependencies:** Run `bun install` to get new packages
2. **Database:** Indexes will be created automatically on startup
3. **Search Index:** Run the build script to index existing content:
    ```bash
    bun run apps/api/src/scripts/build-search-index.ts
    ```
4. **Templates:** System templates are seeded automatically on startup
